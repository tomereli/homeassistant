⚠️ Safety: Prevent Double-Trigger Damage

The Problem

If "Open" is triggered twice consecutively, motor keeps pushing up beyond safe limit → door damage.
Same for "Close" → motor pushes down too far.

🔬 Research Options

❓Check motor for hardware limit switchesPhysical stops at max positions
❓Tuya automation conditionsCan it track "last action"?
💡HA state tracking (fallback)input_select: open/closed, block same-direction commands

HA Protection Logic

Create input_select.garage_door_state with: unknown, open, closed

Open script: Only runs if state ≠ open, then sets state = open
Close script: Only runs if state ≠ closed, then sets state = closed

This prevents consecutive same-direction commands.

⚡ Wiring

Connection Order

1. PSU barrel plug → Female barrel jack adapter
2. Adapter Red (+12V) → Controller VIN+
3. Adapter Black (GND) → Controller VIN-
4. Controller OUT1 → Actuator Wire 1
5. Controller OUT2 → Actuator Wire 2

💡 If actuator moves wrong direction, swap OUT1/OUT2 wires

⚠️ Pivot Points Are Essential

Both actuator ends MUST pivot freely. As door swings in an arc, actuator angle changes. Without pivots → binding force breaks components.

  • Back bracket bolt: loose enough to rotate
  • Front bracket bolt: loose enough to rotate
  • Test full range before tightening

⚠️ Why Shelly Won't Work

Shelly 2PM expects AC shutter motors with separate live wires per direction. DC motors need polarity reversal - the Tuya controller handles this internally.

🔍 Research Findings

⚠️ HomeKit-Only NOT Feasible

Two blockers prevent pure HomeKit implementation:

  1. Face recognition is notification-only - HomeKit can tell you WHO is at the door, but cannot use face detection as an automation trigger
  2. Secure device confirmation - Any automation involving locks requires manual tap to confirm (Apple security policy)

✅ Solution: Aqara Matter Signal Sync + Home Assistant

Aqara G4 supports Matter Signal Sync which can expose "specific face detected" as a virtual occupancy sensor in HomeKit/HA. Combined with HA's dummy switch workaround, this bypasses the secure device limitation.

Yale Linus 2 ✅

✅Can send lock/unlock commands from HA
✅Supports Yale Home, Bluetooth, Matter integration
⚠️Some users report rate limiting issues

✅Can tag family members in Aqara Home app
